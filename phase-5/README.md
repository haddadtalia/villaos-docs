# Phase 5 — Autonomy & Deployment

![Status](https://img.shields.io/badge/status-planned-5A6B82)
![Skills](https://img.shields.io/badge/skills-SLAM_·_Navigation_·_Sensor_Fusion-16243B)

> A mobile robot that maps and navigates the environment autonomously — the capstone of the platform.

## Goal

Bring everything together into an autonomous mobile robot that can map, localize, navigate, and monitor the environment on its own, then integrate and deploy the full platform.

## What it will demonstrate

- **SLAM** — simultaneous localization and mapping
- **Autonomous navigation** and **path planning** (ROS2 Nav2)
- **Sensor fusion** — combining camera, IMU, and distance sensors into one reliable picture
- **Full-system integration** across all previous phases
- Deployment on real robot hardware (e.g. Raspberry Pi)

## Key concept

The mobile robot is what closes the gap between "a smart environment" and "an autonomous robotics platform." It's the capstone that ties every earlier phase into one working system.

## Tech stack

`ROS2` · `Nav2` · `SLAM` · `sensor fusion` · `Raspberry Pi` · `C++ / Python`

## Status

**Planned.** The platform's capstone; integrates all prior phases into an autonomous system.
