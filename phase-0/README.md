> Set up a professional robotics development environment and toolchain from scratch.

## Goal

Build a complete, verified robotics dev environment and establish a clean engineering workflow — so tooling never becomes the bottleneck in later phases.

## What it demonstrates

- **Linux development** on Ubuntu (WSL2), command-line fluency
- **C++ toolchain** — writing, building, and running a C++ program with **CMake**
- **Python environments** — isolated dependencies with `venv`
- **Version control** — Git workflow with SSH authentication to GitHub
- **Project structure** — one-repo-per-project discipline and documentation from day one

## Tech stack

`Ubuntu` · `WSL2` · `C++17` · `CMake` · `Python` · `Git` · `SSH` · `Bash`

## Highlights

- Configured a full compiler + build toolchain and verified it end to end with a working C++ vector-math program (dot & cross product — the basis for coordinate transforms in later phases).
- Set up isolated Python environments with OpenCV installed and confirmed.
- Established the Git/SSH workflow used across the entire platform.

## Status

**Complete.** Environment verified; engineering foundation ready for Phase 1.
