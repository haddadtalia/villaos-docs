> Give the platform sight — recognition and awareness of people, vehicles, and objects.

## Goal

Add perception so the environment can detect and respond to what it sees, running inference efficiently on local hardware.

## What it will demonstrate

- **Computer vision** with **OpenCV** — image processing, filtering, calibration
- **Object, face, and license-plate recognition**
- **Real-time detection and tracking**
- **Deep learning** with **PyTorch** — running and deploying models
- **Edge inference** — efficient inference on local / embedded hardware

## Key concept

Perception turns the platform from something that reacts to switches into something that understands its environment — the prerequisite for intelligent, autonomous behavior.

## Tech stack

`Python` · `OpenCV` · `PyTorch` · `NumPy` · `edge inference`

## Status

**Complete.** Scope defined; implementation follows Phase 1.
