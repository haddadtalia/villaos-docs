## Overview

**VillaOS** is a smart-villa robotics platform I'm building as one integrated system — not a set of disconnected demos. It's a deliberate, multi-phase engineering project designed to take me across the entire robotics-software stack: from embedded devices and IoT networking, through computer vision and AI, into ROS2, kinematics, and a fully autonomous mobile robot.

Every phase plugs into the same ecosystem, so the end result is a coherent **AI + IoT + Robotics platform** — the kind of system robotics companies actually build.
