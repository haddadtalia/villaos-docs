> The pivot: unify every device under ROS2 — the point where a smart home becomes a robotics system.

## Goal

Wrap every capability built so far as **ROS2 nodes**, so the platform becomes one coordinated robotics system where every component communicates through a common framework.

## What it will demonstrate

- **ROS2** architecture — **nodes, topics, services, actions, launch files**
- **Middleware / distributed system design** in C++ and Python
- **Standardized interfaces** between independent components
- **Message-driven, modular robotics software**

## Key concept

This is where a set of connected features becomes a **platform**. Unifying everything under ROS2 is the structural step that makes coordinated, advanced robotic behavior possible — and it's the framework most robotics roles expect.

## Tech stack

`ROS2` · `C++` · `Python` · `colcon` · `rclcpp / rclpy` · `launch files`

## Status

**Planned.** Begins after the perception layer; migrates the dev environment to native Ubuntu for full ROS2 support.
